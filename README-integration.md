# Каталог Lusar на GitHub Pages

Репозиторий: `thelusar/lusar`, ветка `main`. Домен: `lusar.am`.

## Файлы

- `index.html` — существующая стартовая страница с добавленной ссылкой на каталог.
- `catalog.html` — каталог и карточки товаров.
- `assets/catalog.css`, `assets/catalog.js` — оформление и подключение данных.
- `CNAME` — существующий домен, содержимое сохранено.

Обновите эти файлы в корне репозитория, сохранив остальные файлы и настройку GitHub Pages. Сборка, Node.js, токены GitHub и дополнительный сервер для этой страницы не требуются.

## Как это работает

Публичный источник данных: `https://lusar-catalog-studio.sovazones.chatgpt.site/api/storefront`.

Менеджер заполняет карточку и нажимает «Опубликовать на сайте». Страница каталога читает готовые карточки без входа в панель. Изменения, фотографии, категории и удаление товаров обновляются при открытии страницы и каждые 30 секунд, пока вкладка видна. Новые коммиты и повторная загрузка файлов для каждого товара не нужны.

«Вернуть в черновики» скрывает товар из публичного источника. Фото черновиков, заметки для команды, ключи доступа, сессии и служебные поля недоступны публичному каталогу. Родительские категории поддерживаются; пустые категории не показываются.

Цены берутся из панели в AMD. Данные не копируются в GitHub; фотографии хранятся в панели и доступны через отдельные публичные адреса только у опубликованных товаров.

## Проверка после загрузки

1. Откройте `/catalog.html` на домене сайта.
2. Опубликуйте тестовую карточку с фото, артикулом и характеристиками.
3. Убедитесь, что карточка появляется, открывается, находится по артикулу и показывает галерею.
4. Измените цену, затем верните карточку в черновики. Изменение и скрытие должны отразиться после обновления каталога.
